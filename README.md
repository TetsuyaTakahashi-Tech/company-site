# スカイライン・テクノロジーズ 企業サイト

ソフトウェア開発会社「スカイライン・テクノロジーズ」のコーポレートサイトです。
提供サービス、開発の進め方、導入事例、経営チーム紹介、お問い合わせなどのセクションで構成された1ページ構成(シングルページ)のWebサイトです。

## 構成

- `index.html` — サイト本体(HTML/CSS/JSを1ファイルに内包)

## ブラウザで開く手順

1. このリポジトリをクローン、またはダウンロードします。
2. `index.html` をダブルクリックするか、任意のブラウザで開きます。

   ```bash
   open index.html
   ```

   ※ Windowsの場合は `start index.html`、Linuxの場合は `xdg-open index.html` を使用してください。

サーバーの起動やビルド作業は不要で、ファイルを開くだけで閲覧できます。
